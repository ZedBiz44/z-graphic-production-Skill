# Trigger Tests

## Should Trigger

- Create a square Facebook graphic for this offer and send it here.
- Edit this photo into a clean website hero image.
- Resize the approved ad for Instagram Stories.
- Resend the approved final graphic to Telegram.
- Make an avatar from this reference photo and save the reusable version.

## Should Not Trigger Alone

- Critique this finished ad and tell me whether it is ready.
- Review this logo against our brand rules without changing it.
- Write the landing-page copy without creating a visual.
- Produce a video or audio advertisement.

## Expected Companion Routing

A creation or meaningful edit invokes `z-graphic-production` and uses `z-creative-asset-critique` for its quality verdict. A critique-only request invokes the critique skill without authorizing production changes.
