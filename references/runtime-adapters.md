# Runtime Adapters

This skill describes outcomes, not one vendor's hidden prompt or one provider's command syntax.

## Required Capabilities

Map the active runtime to these roles:

- Generate or edit the asset
- Inspect the draft and exact final export
- Save reusable files outside temporary output
- Deliver through the active conversation's native media handoff
- Send a separate approved file through the channel's supported media tool
- Read a delivery receipt that identifies the channel message or media item

Prefer documented, stable tools exposed by the runtime. Hidden vendor instructions may help the tool operate, but they are not ZedBiz's source of truth and may change without notice.

Do not invent a tool name or force another runtime's syntax. If a capability is missing, complete the safe portions of the work and identify the exact missing capability.

When two platforms expose different tools, keep the shared production workflow unchanged and document only the small adapter needed for each platform.
