# Memory and Evidence

Use durable memory for verified lessons, not routine transcripts.

Save a compact pointer only after:

- a real failure was reproduced and recovered;
- a provider, channel, or runtime decision was verified; or
- a reusable project choice was approved.

Record the situation, verified lesson, authoritative technical record, and date. Do not save raw chats, logs, images, secrets, temporary paths, guesses, or one-off prompt text.

Keep technical evidence in the approved GitHub issue or repository. Keep operating guidance in the approved Notion SOP. Memory should point to those sources rather than duplicating them.
